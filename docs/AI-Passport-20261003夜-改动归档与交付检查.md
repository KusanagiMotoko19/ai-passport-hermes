## 2. 今晚排掉的 bug（都实测验证过）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 屏幕每行末尾都是省略号、正文发不全 | 换行函数行满时对"非空格"一律**截断 + 打 `...`**，中文没有空格 → 每个满行都命中 | 改成按字符断行、不打点 |
| 2 | **第二行只有一个字** | 量宽度写成 `end - line + 1`，对 3 字节中文只量到 2/3 个字 → 每行少放一字、那字被挤成孤行 | 按完整字符量（`next - line`） |
| 3 | 行首出现逗号 | 无避头尾 | 断点落在标点上时，**把本行末字也留给下一行**（⚠ 不能"超宽硬塞"——渲染层会裁掉，标点和前一个字一起消失） |
| 4 | 正文超一屏滚不到底 | 滚动上限按 10px/行算，实测行距 **21px** → 上限偏小一半 | `TEXT_LINE_H` 改 21 |
| 5 | 正文最后一行可能被吃掉 | 换行会插 `\n`，输出缓冲只有 512 字节（与输入同大）→ 静默溢出截断 | 输出缓冲提到 768 |
| 6 | 桥崩了不会自己起来 | 计划任务只有"登录时"触发器 | 加看门狗（每 5 分钟检查，不在就拉起） |

## 3. ⚠️ 请你留意的事（这些你可能没想到）

1. **工牌屏只显示摘要，永远看不到我的全文** —— 这是**设计**（BLE 分片丢包），不是 bug。要看全文在电脑上。
2. **`D:\ai-passport` 没有版本控制**（不是 git 仓库）。今晚的改动已手动备份到 `D:\ai-passport\backup\20261003-night\`（源码 + 桥 + 固件二进制，16MB）。**建议**：以后每次改完都跑一次备份，或给这个目录 `git init`。
3. **桥依赖 Hermes 的 `state.db` 表结构** —— Hermes 大版本升级如果改了 schema，桥会读不到消息（症状：屏上一直不更新、日志里没有"下发正文"）。升级后留意这一点。
4. **BLE 配对码**：刷机保留 nvs，不用重配；但「恢复出厂」或换电脑后要重新配对（设备屏会显示 6 位码）。
5. **设备没有电量显示** —— 用久了突然黑屏，先想起充电。
6. **耳机式的"滴"**：Hermes 干活期间会每 3 秒滴一声（设计如此）。如果嫌吵，设备菜单里关「提示音」就行。
7. **看门狗只保证"进程活着"**，不保证"BLE 连着"。如果桥进程在但设备不亮，手动重启一次桥（停 → 等 3 秒 → 起）。
8. **工牌是戴在身上的** —— 屏上内容旁人可见。我写摘要时不会放敏感信息，你也要注意场合。
9. **`bridge/` 目录里堆了 15+ 个调试脚本**（probe_*/pair_*/listen_*）—— 不影响运行，哪天可以清一清。
